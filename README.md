# Конспекты по психологии (docs-as-code)

Личный сайт-конспект: семестры → дисциплины → лекции. Markdown-файлы автоматически превращаются в сайт с деревом навигации и полнотекстовым поиском.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Как добавить конспект

Создайте markdown-файл в папке `content/`:

```
content/
  Семестр 1/
    Клиническая психология/
      01 Введение в клиническую психологию.md
      02 Биопсихосоциальная модель.md
    Психодиагностика/
      01 Предмет и задачи психодиагностики.md
  Семестр 2/
    Нейропсихология/
      01 Синдромный анализ.md
```

Правила:

- **Числовой префикс** (`01 `, `02 `) задаёт порядок лекций и не отображается в интерфейсе.
- **Название лекции** берётся из имени файла (префикс отбрасывается, `_` → пробел).
- **Frontmatter** (необязательно) позволяет переопределить название и порядок:

  ```yaml
  ---
  title: Кастомное название лекции
  order: 5
  ---
  ```

- Поддерживается GFM: таблицы, чек-листы, зачёркивание, автоматические ссылки.
- Папки: `семестр/дисциплина/лекция.md` — ровно три уровня вложенности.

## Поиск

Клиентский нечёткий поиск (Fuse.js) по заголовкам и полному тексту всех лекций — работает без бэкенда, индекс строится при загрузке страницы.

- `Ctrl`/`Cmd` + `K` или `/` — перейти к поиску;
- `↑` `↓` — перемещение по результатам, `Enter` — открыть, `Esc` — закрыть;
- совпадения в результатах подсвечиваются, рядом показывается фрагмент текста.

## Стек

- **Vite + React + TypeScript** — сборка и UI;
- **react-markdown + remark-gfm** — рендер markdown;
- **Fuse.js** — нечёткий поиск;
- **lucide-react** — иконки;
- **js-yaml** — опциональный frontmatter.

Тёмная тема включается кнопкой в шапке; по умолчанию берётся системная.
