# Конспекты по психологии (docs-as-code)

Личный сайт-конспект: семестры → дисциплины → лекции. Markdown-файлы автоматически превращаются в сайт с деревом навигации и полнотекстовым поиском.

Разделы сайта: **Конспекты**, **Материалы** (файлы и ссылки по дисциплинам), **Книги**, **Дедлайны**.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Как добавить конспект

Создайте markdown-файл в папке `content/`:

```
content/
  Семестр 1/
    Клиническая психология/
      01 Введение в клиническую психологию.md
      02 Биопсихосоциальная модель.md
    Психодиагностика/
      01 Предмет и задачи психодиагностики.md
  Семестр 2/
    Нейропсихология/
      01 Синдромный анализ.md
```

Правила:

- **Числовой префикс** (`01 `, `02 `) задаёт порядок лекций и не отображается в интерфейсе.
- **Название лекции** берётся из имени файла (префикс отбрасывается, `_` → пробел).
- **Frontmatter** (необязательно) позволяет переопределить название и порядок:

  ```yaml
  ---
  title: Кастомное название лекции
  order: 5
  ---
  ```

- Поддерживается GFM: таблицы, чек-листы, зачёркивание, автоматические ссылки.
- Папки: `семестр/дисциплина/лекция.md` — ровно три уровня вложенности.

## Как добавить новый семестр

Семестр — это папка в `content/`:

```
content/
  Семестр 2/
    Нейропсихология/
      01 Синдромный анализ.md
```

Правила:

- **Порядок семестров** задаётся числовым префиксом папки: `01 Семестр 1`, `02 Семестр 2`. Без префикса семестры сортируются по названию (естественная сортировка: «Семестр 10» встанет после «Семестр 9»).
- Папки и файлы могут содержать пробелы, запятые и кириллицу — URL на сайте повторяет путь файла.
- Семестр появится на сайте, только если в нём есть хотя бы одна дисциплина с конспектом (`.md`): пустые папки в дереве не отображаются.
- Если для дисциплин семестра нужны учебные материалы (файлы и ссылки), создайте одноимённую папку семестра в `materials/` — подробности в [materials/README.md](materials/README.md).

## Как добавить дисциплину в существующий семестр

1. Создайте в `content/<семестр>/` папку дисциплины со следующим номером префикса и хотя бы одним конспектом:

   ```
   content/Семестр 1/
     09 Возрастная психология/
       01 Установочная встреча по дисциплине.md
   ```

2. Если нужны материалы — создайте папку с **точно таким же именем** в `materials/<семестр>/` и положите туда файлы: подробности в [materials/README.md](materials/README.md).

Правила:

- Префикс (`09 `) задаёт позицию дисциплины в списке и не отображается в интерфейсе. Работают варианты разделителя: `09 `, `09.`, `09-`, `09_`.
- Название берётся из имени папки (префикс отбрасывается, `_` заменяется на пробел).
- Имена папок дисциплин в `content/` и `materials/` должны совпадать посимвольно.
- Дисциплина может существовать только с конспектами или только с материалами: первая будет в дереве конспектов, вторая — в разделе «Материалы».

## Скилл для агентов

Правила вёрстки конспектов оформлены как OpenCode-скилл: `.agents/skills/note-format/`. Агент подхватывает его автоматически при создании или переоформлении конспектов. Внутри — `references/template.md` (шаблон) и `scripts/check.mjs` (проверка разметки).

Проверить разметку вручную:

```sh
node .agents/skills/note-format/scripts/check.mjs "content/<путь к файлу>.md"
```

## Поиск

Клиентский нечёткий поиск (Fuse.js) по заголовкам и полному тексту всех лекций — работает без бэкенда, индекс строится при загрузке страницы.

- `Ctrl`/`Cmd` + `K` или `/` — перейти к поиску;
- `↑` `↓` — перемещение по результатам, `Enter` — открыть, `Esc` — закрыть;
- совпадения в результатах подсвечиваются, рядом показывается фрагмент текста.

## Стек

- **Vite + React + TypeScript** — сборка и UI;
- **react-markdown + remark-gfm** — рендер markdown;
- **Fuse.js** — нечёткий поиск;
- **lucide-react** — иконки;
- **js-yaml** — опциональный frontmatter.

Тёмная тема включается кнопкой в шапке; по умолчанию берётся системная.
