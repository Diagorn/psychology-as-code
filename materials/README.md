# Материалы

Учебные материалы по дисциплинам: файлы и ссылки на внешние ресурсы. На сайте —
вкладка «Материалы»: обзорная страница со всеми дисциплинами (поиск и фильтр по
семестру) и страница каждой дисциплины со списком файлов и ссылок.

## Структура

```
materials/
  Семестр 1/
    Теории личности в психологии/
      Рабочая программа дисциплины.pdf   ← файл материала
      Темы рефератов.docx
      index.json                         ← описание, ссылки, уточнения (опционален)
    История возникновения гештальт-терапии, ее философские и методологические основания/
      Введение в курс.pdf
      index.json
```

Правила:

- Два уровня папок: `<Семестр>/<Дисциплина>/`. Имена семестров и дисциплин должны
  совпадать с папками в `content/` посимвольно — тогда материалы легко найти по
  нужной дисциплине.
- **Порядок** задаётся числовым префиксом папки (`01 `, `02 `): префикс
  отбрасывается, `_` заменяется на пробел. Работают варианты разделителя:
  `01 `, `01.`, `01-`, `01_`. Без префикса — естественная сортировка по названию.
- Папки и файлы могут содержать пробелы, запятые и кириллицу — URL повторяет путь.
- Дисциплина может существовать только здесь, без конспектов в `content/`:
  она появится в разделе «Материалы», но не в дереве конспектов.

## Как добавить семестр

Создайте папку семестра, внутри — папку дисциплины хотя бы с одним файлом или
`index.json`. Пустые папки на сайте не отображаются — сайт строится только из файлов.

## Как добавить дисциплину в существующий семестр

1. Создайте в `materials/<семестр>/` папку с именем дисциплины **один в один** как в `content/` (со следующим номером префикса, если используете нумерацию):

   ```
   materials/Семестр 1/
     09 Возрастная психология/
   ```

2. Положите туда файлы и, при желании, `index.json` (см. ниже). Дисциплина появится
   на обзорной странице «Материалов», а на её странице — файлы и ссылки.

## Файлы

Просто кладите файлы в папку дисциплины — на сайт они попадают автоматически
(всё, кроме `index.json`). Название материала = имя файла; его можно переопределить
в `index.json`. На странице дисциплины клик по названию открывает файл, кнопка
справа скачивает его.

## Ссылки и описания: index.json

Опциональный `index.json` в папке дисциплины описывает набор материалов:

```json
{
  "description": "Программа, методички и презентации",
  "links": [
    {
      "title": "eLibrary.ru — научная электронная библиотека",
      "url": "https://elibrary.ru/",
      "description": "Поиск статей по теме дисциплины"
    }
  ],
  "files": {
    "Рабочая программа.pdf": {
      "title": "Рабочая программа дисциплины",
      "description": "Утверждена в 2025 году"
    }
  }
}
```

Поля (все необязательны):

| Поле | Что делает |
|---|---|
| `description` | Подпись на карточке дисциплины и под заголовком страницы материалов |
| `links` | Внешние ссылки: `title`, `url`, необязательный `description`. Открываются в новой вкладке |
| `files` | Уточнения к файлам по имени файла: `title` (как показывать вместо имени) и `description` |

- Без `index.json` тоже можно: достаточно положить файлы в папку.
- Можно указать только `links` — дисциплина с одними ссылками отображается нормально.
- Битый `index.json` сайт не ломает — остаются значения по умолчанию (имена файлов,
  без описаний).

## Проверки

Dev-сервер подхватывает новые папки и файлы сам (HMR). Перед публикацией
прогоните `npm run build` — раздел сканируется на этапе сборки.
