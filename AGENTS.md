# AGENTS.md

Инструкции для AI-агентов, работающих в этом репозитории. Проект — личный сайт-конспект
магистранта программы «Гештальт-подход в психологическом консультировании»:
markdown-файлы автоматически превращаются в сайт с деревом навигации и поиском.

## Команды

```sh
npm install
npm run dev       # dev-сервер на http://localhost:5173
npm run build     # tsc --noEmit (strict) + vite build — всегда прогонять перед сдачей работы
npm run preview   # локальный просмотр production-сборки

# Проверка разметки конспекта тем же стеком, что рендерит сайт:
node .agents/skills/note-format/scripts/check.mjs "content/<путь к .md>"
```

## Архитектура

- **Vite + React + TypeScript**, сборка strict (`tsc --noEmit` должен проходить без ошибок).
- `src/lib/content.ts` — сканирует `content/**/*.md` через `import.meta.glob` (eager, raw),
  строит дерево семестр → дисциплина → лекция. Frontmatter (`title`, `order`) парсится
  через js-yaml и вырезается перед рендером.
- `src/lib/search.ts` — клиентский нечёткий поиск (Fuse.js) по заголовкам и тексту;
  индекс строится при загрузке страницы, бэкенда нет.
- Роутинг — `HashRouter`: `/<семестр>/<дисциплина>/<лекция>`; URL-путь совпадает с путём
  файла в `content/` (папки и файлы могут содержать пробелы, запятые и кириллицу).
- Рендер markdown — `react-markdown` + `remark-gfm`; **HTML в конспектах не рендерится**.
- Раздел «Книги»: `src/lib/books.ts` на этапе сборки сканирует `books/*/` (`settings.json`,
  md-конспект, pdf через `?url`); роуты `/books` (карточки с поиском и фильтром по предмету)
  и `/books/<папка>` (конспект книги). В шапке — вкладки Конспекты/Книги; на «Книгах»
  сайдбар и общий поиск по конспектам скрыты.
- Стили — рукописный CSS в `src/index.css`: токены light/dark (`:root` / `[data-theme='dark']`),
  фиолетовый акцент, серифная типографика статьи. Тёмная тема хранится в `localStorage`.
- Иконки — `lucide-react`.

## Контент (`content/`)

- Структура строго трёхуровневая: `content/<семестр>/<дисциплина>/<NN Название>.md`.
  Пустых папок в дереве не видно — сайт строится только из файлов.
- **Числовой префикс** (`01 `, `02 `) задаёт порядок лекций и не отображается.
- Название лекции берётся из имени файла (префикс отбрасывается) или из frontmatter `title`.
- Форматирование конспектов — строго по скиллу **`.agents/skills/note-format/SKILL.md`**:
  там каркас файла, правила таблиц/цитат/чек-листов и шаблон. Прочитай его перед
  созданием или вёрсткой конспекта и проверь результат `check.mjs`.
- Работая с расшифровками встреч: сохранять все факты, ничего не досочинять; очевидные
  опечатки в именах и терминах исправлять на общепринятые (Зейгарник, Кочюнас, Гезелл,
  Эльконин, Петражицкий и т.п.) и перечислять исправления пользователю в ответе.
- Если данных не хватает (дата, спикер) — писать «уточнить», не выдумывать.

## Книги (`books/`)

- Конспекты книг — по скиллу **`.agents/skills/book-notes/SKILL.md`**: одна книга —
  одна папка `books/<короткое-имя>/` с исходником (PDF/EPUB), `конспект.md` и
  `settings.json` (автор, название, предмет, тип).
- Оглавление книги в сайдбаре: по умолчанию h2 — части (раскрывающиеся папки),
  h3 — главы внутри. Если `settings.json` задаёт `"toc": "flat"`, оглавление плоское:
  главы (h2) обычным списком, подразделы (h3) в меню не показываются.
- Вёрстка книжных конспектов — по скиллу `note-format`, проверка — тем же `check.mjs`;
  `npm run build` для `books/` не нужен (сайт `books/` не сканирует).

## Проверки перед завершением работы

1. Изменил `content/` → `check.mjs` по каждому затронутому файлу + `npm run build`.
2. Изменил `books/` → `check.mjs` по конспекту (`content/` и сайт не затронуты).
3. Изменил `src/` → `npm run build`.
4. После изменений контента dev-сервер подхватывает их сам (HMR), перезапуск не нужен.

## Git

- Работаем в `main`; **commit и push — только по явной просьбе пользователя**.
- Сообщения коммитов — краткие, на русском, с префиксом: `content:` для конспектов,
  `feat:` / `fix:` для кода. Логически разные изменения — отдельными коммитами
  (например, разделение лекции и вёрстка остальных конспектов).
- Пользовательские правки в рабочей копии (файлы, которые агент не менял) не терять:
  коммитить вместе с остальным или отдельным коммитом, уточняя у пользователя.

## Стиль

- UI и конспекты — на русском; даты «12 октября 2026 г.», диапазоны через тире «20–40 минут».
- Дизайн минималистичный: не добавлять зависимостей «для красоты», стили — в общий CSS
  с токенами, поддерживать обе темы (light/dark).
